# README media

`drive-preview.gif` selects four excerpts from the [47-second Codex recording](../../evidence/codex-demos-2026-10-06/drive.mp4).
It crops the prompt and result for readability, samples at 6fps and loops.
Waiting is omitted; the original 8× working label remains visible, and the
seven-second motion excerpt retains its original playback speed. No scene,
chat or result imagery is synthesized. The simulator and car were prepared;
Jev is not used in this recording.

`route-poster.jpg` is the original frame at 33 seconds in the
[Jev route recording](../../evidence/route-hazards-2026-10-05/demo.mp4).
It shows the cut-in trial and a recorded `caution` choice. The separate
pedestrian attempt did not enter the lane. These are exploratory trials.

[manifest.json](manifest.json) records source hashes, selections, crops,
timing, output hashes and verification. The original videos and their evidence
remain unchanged.

The manifest also records the three GitHub video attachments used for inline
README playback. The complete drive recording is compressed to 720p with all
1,421 frames and the original timing; the camera and route attachments are
byte-identical to their published source videos. The repository copies remain
available as independent source artifacts.
